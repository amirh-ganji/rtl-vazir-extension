# راست‌چین‌کن + فونت وزیر

اکستنشن کروم که با یک کلیک:
- جهت صفحه‌ی فعلی را **راست‌به‌چپ (RTL)** می‌کند
- فونت تمام صفحه را به **وزیرمتن (Vazirmatn)** تغییر می‌دهد
- با کلیک دوباره، همه چیز به حالت اول (چپ‌به‌راست و فونت اصلی سایت) برمی‌گردد

## نصب (حالت Developer / Unpacked)

1. فایل zip را از حالت فشرده خارج کنید (Extract).
2. مرورگر کروم را باز کنید و به آدرس زیر بروید:
   ```
   chrome://extensions
   ```
3. گزینه‌ی **حالت توسعه‌دهنده (Developer mode)** را در گوشه‌ی بالا سمت راست فعال کنید.
4. روی دکمه‌ی **Load unpacked** (بارگذاری بدون بسته‌بندی) کلیک کنید.
5. پوشه‌ی استخراج‌شده (`rtl-vazir-extension`) را انتخاب کنید.
6. آیکون افزونه در نوار ابزار کروم ظاهر می‌شود.

## استفاده

### کل صفحه
1. وارد هر صفحه‌ای شوید.
2. روی آیکون افزونه کلیک کنید.
3. دکمه‌ی «فعال کردن راست‌چین کل صفحه» را بزنید.
4. برای بازگشت، دوباره روی همان دکمه کلیک کنید.

### فقط یک بخش خاص
1. روی آیکون افزونه کلیک کنید.
2. دکمه‌ی «انتخاب بخشی از صفحه» را بزنید (پاپ‌آپ بسته می‌شود).
3. روی صفحه، وقتی موس را روی بخش‌های مختلف می‌برید، دور آن‌ها یک خط‌چین آبی می‌افتد.
4. روی بخش موردنظر کلیک کنید → همان بخش راست‌چین و با فونت وزیر می‌شود.
5. می‌توانید چند بخش مختلف را همین‌طور پشت‌سرهم انتخاب کنید.
6. برای خروج از حالت انتخاب، دکمه‌ی «پایان» (بالای صفحه) یا کلید Escape را بزنید.
7. برای برگرداندن یک بخش انتخاب‌شده، دوباره وارد حالت انتخاب شوید و روی همان بخش کلیک کنید (روشن/خاموش می‌شود).
8. برای پاک‌کردن همه‌ی بخش‌های انتخاب‌شده به‌یک‌باره، از دکمه‌ی «پاک‌کردن انتخاب‌های بخشی» در پاپ‌آپ استفاده کنید.

> توجه: این تغییرات فقط روی **تب فعلی** اعمال می‌شود و با رفرش یا رفتن به صفحه‌ی دیگر، دوباره باید فعال شود.
> همچنین فونت وزیرمتن از یک CDN آنلاین (jsdelivr) بارگذاری می‌شود، پس نیاز به اتصال اینترنت دارد.

## نکات فنی

- ساخته‌شده با Manifest V3
- از `chrome.scripting.executeScript` برای تزریق استایل به تب فعال استفاده می‌کند (نیازی به دسترسی دائمی به همه‌ی سایت‌ها ندارد، فقط `activeTab`)
- فونت از پکیج [Vazirmatn](https://github.com/rastikerdar/vazirmatn) بارگذاری می‌شود
